# 📊 Análise de Vendas com IA (Prompts)

Este projeto tem como objetivo analisar relatórios de vendas utilizando técnicas de Engenharia de Prompts com inteligência artificial, extraindo insights estratégicos para tomada de decisão.

---

## 🎯 Objetivo

Aplicar prompts estruturados para:
- Interpretar dados de vendas
- Identificar padrões e tendências
- Gerar insights úteis para o negócio

---

## 🛠️ Ferramentas utilizadas

- Planilhas (Excel/CSV)
- Inteligência Artificial baseada em LLMs
- Engenharia de Prompts
- GitHub para documentação

---

## 📂 Dados utilizados

Os dados estão localizados na pasta `/dados` e contêm informações como:
- Produtos vendidos
- Quantidade
- Receita
- Datas de venda

---

## 💬 Exemplos de prompts utilizados

- "Analise os dados de vendas e identifique os produtos mais vendidos."
- "Quais padrões podem ser observados nas vendas mensais?"
- "Quais produtos têm maior margem de crescimento?"
- "Gere insights estratégicos com base nesses dados."

---

## 📈 Insights obtidos

- Produtos X e Y são os mais vendidos no período analisado
- Houve aumento de vendas em determinados meses sazonais
- Alguns produtos têm baixa performance constante
- Oportunidades de melhoria em categorias específicas

---

## 🚀 Conclusão

O uso de prompts bem estruturados permitiu transformar dados brutos em informações estratégicas, auxiliando na tomada de decisão baseada em dados.
